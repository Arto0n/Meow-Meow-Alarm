## ✨ امکانات برنامه

میو میو آلارم یک ساعت زنگ‌دار معمولی نیست؛ وقتی زمان آلارم می‌رسد، گربه با میوکردن توجهت را جلب می‌کند و می‌توانی با نوازش و غذا دادن، در یک صحنهٔ تعاملی به او رسیدگی کنی.

- **چند آلارم مستقل:** ساخت، ویرایش، حذف، فعال یا غیرفعال‌کردن، انتخاب نام و تعیین روزهای تکرار.
- **طراحی دوبعدی اصلی و دنج:** اتاق، گربه و شخصیت انسان با همان سبک تصویری اصلی برنامه؛ بدون پیکسل‌آرت یا مدل سه‌بعدی.
- **۶ صدای میو:** گزینه‌های «میو ۱» تا «میو ۶» همراه با قابلیت پیش‌شنیدن.
- **میوی سراسری و اختصاصی:** به‌صورت پیش‌فرض آلارم‌ها از صدای سراسری استفاده می‌کنند؛ برای هر آلارم می‌توان صدای مخصوص تعیین کرد یا فایل دلخواه وارد کرد.
- **۳ صدای خرخر:** «خرخر ۱» تا «خرخر ۳» به‌همراه امکان واردکردن خرخر شخصی و شنیدن پیش‌نمایش.
- **شخصی‌سازی گربه:** انتخاب ظاهر/رنگ، ثبت نام گربه و نمایش نام انتخاب‌شده در متن‌های مربوط به او.
- **تعامل هنگام بیداری:** نوازش، خواب موقت (Snooze)، غذا دادن و انیمیشن‌های شخصیت.
- **زمان‌بندی قابل تنظیم:** تنظیم زمان فعالیت‌های گربه و رفتارهای شخصیت داخل صحنه.
- **نمایش آلارم روی صفحهٔ قفل:** پخش صدا از سرویس اندروید و امکان نمایش اعلان تمام‌صفحه در گوشی‌هایی که اجازه می‌دهند.
- **راهنمای مجوزها در اولین اجرا:** راهنمای اعلان‌ها، آلارم دقیق و نمایش تمام‌صفحه؛ برخی تنظیمات باتری و اجرای خودکار باید دستی فعال شوند.
- **کارکرد آفلاین:** صداهای همراه برنامه برای پخش به اینترنت نیاز ندارند.

دکمهٔ **تست ۵ ثانیه‌ای** و ابزارهای آزمایشی دیگر فعلاً عمداً حفظ شده‌اند تا بررسی و توسعهٔ برنامه ساده‌تر باشد.

## 📱 دانلود و نصب APK

در حال حاضر نسخهٔ رسمی در Google Play ارائه نشده و فایل قابل نصب از طریق **GitHub Actions** به‌صورت Debug APK ساخته می‌شود:

1. صفحهٔ [ساخت APK در GitHub Actions](https://github.com/Arto0n/Meow-Meow-Alarm/actions/workflows/build-apk.yml) را باز کن.
2. آخرین اجرای موفق (علامت سبز) را انتخاب کن. در صورت نیاز، با گزینهٔ **Run workflow** شاخهٔ `main` را اجرا کن.
3. از بخش **Artifacts** فایل **`MeowAlarm-debug`** را دانلود کن. ممکن است لازم باشد وارد حساب GitHub شوی.
4. فایل ZIP دریافتی را استخراج کن و **`app-debug.apk`** را به گوشی اندرویدی انتقال بده.
5. فایل APK را از منبعی که به آن اعتماد داری نصب کن و مراحل دسترسی‌های شروع برنامه را تکمیل کن.
6. هم **تست ۵ ثانیه‌ای** و هم یک آلارم واقعی را با گوشی قفل‌شده و برنامهٔ بسته امتحان کن.

> **توجه به امضای Debug:** ممکن است نسخه‌های ساخته‌شده با کلیدهای متفاوت روی نسخهٔ قبلی نصب نشوند. حذف برنامهٔ قبلی می‌تواند آلارم‌ها و تنظیمات ذخیره‌شده را پاک کند؛ قبل از حذف، از آن‌ها یادداشت یا پشتیبان داشته باش.

## 🔔 دسترسی‌های اندروید و اجرای مطمئن آلارم

برای زنگ‌خوردن درست، بسته به نسخهٔ اندروید و مدل گوشی ممکن است دسترسی‌های زیر لازم باشد:

| دسترسی یا تنظیم | کاربرد |
| --- | --- |
| آلارم دقیق (Exact Alarm) | اجرای آلارم در ساعت انتخاب‌شده |
| اعلان‌ها (Notifications) | نمایش اعلان آلارم در زمان زنگ |
| اعلان تمام‌صفحه (Full-screen) | نمایش صفحهٔ تعاملی گربه روی صفحهٔ قفل در صورت اجازهٔ سیستم |
| اجرای پس‌زمینه | ادامهٔ پخش آلارم وقتی برنامه روی صفحه نیست |
| محدودیت باتری و Autostart | جلوگیری از متوقف‌شدن فعالیت برنامه در بعضی گوشی‌ها، به‌ویژه شیائومی |

**هیچ اپلیکیشنی نمی‌تواند تأیید دسترسی‌های حساس اندروید را به کاربر تحمیل کند.** صفحهٔ راه‌اندازی فقط درخواست مجوز یا مسیر فعال‌سازی آن را نشان می‌دهد.

توضیح کامل‌تر را در [راهنمای دسترسی‌های اندروید](docs/ANDROID_PERMISSIONS.md) و [رفع اشکال](docs/TROUBLESHOOTING.md) بخوان.

## 🛠️ ساخت برنامه از روی سورس

بعد از تغییر نام مخزن در GitHub، می‌توان پروژه را این‌طور دریافت کرد:

```bash
git clone https://github.com/Arto0n/Meow-Meow-Alarm.git
cd Meow-Meow-Alarm
```

تا قبل از تکمیل تغییر نام، آدرس فعلی [`Arto0n/MeowAlarm3`](https://github.com/Arto0n/MeowAlarm3) را استفاده کن.

در محیط دارای **JDK 17، Android SDK 34، Build Tools 34.0.0 و Gradle 8.9** دستور زیر را اجرا کن:

```bash
gradle --no-daemon clean assembleDebug
```

فایل خروجی در مسیر زیر ساخته می‌شود:

```text
app/build/outputs/apk/debug/app-debug.apk
```

ممکن است پروژه فایل `gradlew` نداشته باشد؛ در این حالت ساده‌ترین روش ساخت همان **GitHub Actions** است. برای بررسی اولیهٔ سورس:

```bash
python tests/verify_sources.py
```

## 🗺️ وضعیت توسعه

میو میو آلارم یک **پروژهٔ شخصی و در حال توسعه** است. هدف اصلی، پایداری آلارم روی گوشی‌های مختلف و بهبود همان رابط دوبعدی اصلی است. بعضی تولیدکنندگان گوشی، به‌خصوص در مدیریت باتری و اجرای پس‌زمینه، محدودیت‌های خاصی دارند؛ بنابراین عملکرد یکسان روی همهٔ مدل‌ها تضمین نمی‌شود.

نسخهٔ فعلی یک **Debug APK** است، نه نسخهٔ رسمی فروشگاهی با امضای انتشار ثابت.
