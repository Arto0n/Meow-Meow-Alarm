## میو میو آلارم چیست؟

**میو میو آلارم** یک اپلیکیشن آلارم تعاملی و دوست‌داشتنی برای اندروید است. این برنامه به‌جای یک آلارم ساده و خشک، از یک فضای دوبعدی گرم و صمیمی، صدای میو و خرخر گربه، و یک روند بیدارشدن بازی‌گونه استفاده می‌کند.

وقتی آلارم زنگ می‌خورد، برنامه صفحهٔ گربه را باز می‌کند تا با نوازشش آرامش کنی؛ فقط خاموش‌کردن یک زنگ معمولی نیست.

## اتاق گربه

<img src="./docs/images/preview-room.png" alt="نمای اتاق گربه" width="370">

با زنگ‌خوردن آلارم، صدای میو و صحنهٔ تعاملی گربه ظاهر می‌شود. می‌توانی گربه را نوازش کنی و صدای خرخرش را بشنوی. مدت نوازش، اسنوز و زمان‌بندی حرکت‌های اتاق قابل تنظیم‌اند.

## آلارم‌ها

<img src="./docs/images/preview-alarms.png" alt="صفحهٔ مدیریت آلارم‌ها" width="370">

چند آلارم با ساعت، نام و روزهای تکرار متفاوت بساز؛ هرکدام را جداگانه روشن، خاموش، ویرایش یا حذف کن. آلارم بعدی هم در صفحهٔ اصلی مشخص است.

## صداها و شخصی‌سازی

<img src="./docs/images/preview-settings.png" alt="انتخاب صدا و ظاهر گربه" width="370">

برنامه **۶ صدای میو** و **۳ صدای خرخر** دارد. می‌توانی برای همهٔ آلارم‌ها یک میوی پیش‌فرض انتخاب کنی یا برای هر آلارم صدای جداگانه، حتی فایل دلخواه خودت، بگذاری. برای خرخر هم امکان انتخاب صدای شخصی وجود دارد.

اسم گربه را خودت تعیین کن و رنگش را از بین خاکستری راه‌راه، نارنجی، مشکی، سفید و سه‌رنگ انتخاب کن. متن‌های مربوط به گربه با اسم انتخابی هماهنگ می‌شوند.

## نصب

فایل APK را از بخش **[Releases](https://github.com/Arto0n/Meow-Meow-Alarm/releases)** دانلود و روی گوشی اندرویدی نصب کن (اندروید ۸ یا جدیدتر). در اجرای اول، مجوزهای اعلان، آلارم دقیق و نمایش آلارم روی صفحهٔ قفل را طبق راهنمای برنامه بررسی کن. بسته به مدل گوشی، ممکن است لازم باشد محدودیت باتری برنامه را هم تغییر بدهی.

> نسخه‌هایی که با عنوان **Preview** منتشر می‌شوند، برای آزمایش‌اند و ممکن است برای نصب روی نسخهٔ قبلی به نصب مجدد نیاز داشته باشند.

## سورس و ساخت برنامه

برنامه با **Kotlin** و یک رابط تعاملی **HTML / CSS / JavaScript** ساخته شده است. برای ساخت APK از GitHub Actions در بخش **Actions** مخزن استفاده کن. پیش‌نیازهای توسعه: **JDK 17**، **Android SDK 34** و **Gradle 8.9**.
