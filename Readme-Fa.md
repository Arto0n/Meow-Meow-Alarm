## میو میو آلارم چیست؟

**Meow Meow Alarm** یک اپلیکیشن آلارم تعاملی و دوست‌داشتنی برای اندروید است.
این برنامه به‌جای یک آلارم ساده و خشک، از یک فضای دوبعدی گرم و صمیمی، صدای میو و خرخر گربه، و یک روند بیدارشدن بازی‌گونه استفاده می‌کند.

وقتی آلارم زنگ می‌خورد، برنامه می‌تواند یک صحنهٔ تعاملی باز کند تا کاربر فقط شنوندهٔ صدا نباشد، بلکه با خود آلارم درگیر شود.

---

## ایدهٔ اصلی برنامه

تجربهٔ برنامه روی سه بخش اصلی بنا شده است:

1. **صحنهٔ تعاملی بیدارباش**
2. **مدیریت کامل آلارم‌ها**
3. **شخصی‌سازی صداها و خود گربه**

---

## قابلیت‌های اصلی برنامه

### ۱) تجربهٔ تعاملی آلارم
- صحنهٔ دوبعدی Cozy با همان شخصیت اصلی مرد و گربه
- صفحهٔ تعاملی هنگام زنگ خوردن آلارم به‌جای یک پنجرهٔ ساده
- تعامل نوازش گربه به‌عنوان بخشی از روند آلارم
- پخش میو، خرخر و واکنش‌های صحنه
- پشتیبانی از بازشدن تمام‌صفحه / روی صفحهٔ قفل در صورت فعال‌بودن مجوزها
- طراحی شده برای بازکردن مستقیم صفحهٔ تعاملی آلارم بعد از زنگ خوردن

### ۲) مدیریت آلارم‌ها
- ساخت چندین آلارم
- روشن / خاموش‌کردن مستقل هر آلارم
- ویرایش آلارم‌های موجود
- حذف آلارم‌های ذخیره‌شده
- تعیین عنوان برای هر آلارم
- تنظیم تکرار برای روزهای دلخواه هفته
- نمایش آلارم بعدی
- داشتن ابزارهای تست داخلی
- تست سریع ۵ ثانیه‌ای برای بررسی عملکرد

### ۳) سیستم صدا
#### پریست‌های میو
- چند پریست میوی داخلی
- نام‌گذاری ساده و خنثی: **میو ۱، میو ۲، میو ۳، ...**
- میوی پیش‌فرض سراسری برای همهٔ آلارم‌ها
- امکان Override برای هر آلارم به‌صورت جداگانه
- امکان انتخاب فایل صوتی اختصاصی برای هر آلارم

#### پریست‌های خرخر
- چند پریست خرخر داخلی
- نام‌گذاری ساده و خنثی: **خرخر ۱، خرخر ۲، خرخر ۳، ...**
- امکان انتخاب خرخر سفارشی
- دکمهٔ پیش‌شنیدن برای خرخرها
- پخش تمیزتر و متعادل‌تر صدای خرخر

### ۴) شخصی‌سازی گربه
- امکان انتخاب اسم برای گربه
- تغییر متن‌های مرتبط در بخش‌های مختلف برنامه بر اساس اسم انتخاب‌شده
- پریست‌های ظاهری / رنگی برای گربه
- رنگ‌های فعلی برنامه شامل:
  - خاکستری / راه‌راه
  - نارنجی
  - مشکی
  - سفید
  - سه‌رنگ

### ۵) شخصی‌سازی روند داستان / زمان‌بندی
- تنظیم زمان‌بندی تعامل‌ها
- حالت‌های آمادهٔ زمان‌بندی (مثلاً: آرام، کلاسیک، سریع)
- قابلیت تنظیم زمان مراحل مختلف روند بیدارباش
- از جمله مواردی مثل:
  - مدت نوازش
  - تأخیر بین مراحل داستان
  - زمان‌بندی سیگار کشیدن
  - زمان رسیدن غذا
  - مدت ریختن غذا

### ۶) مجوزها و یکپارچگی با اندروید
- صفحهٔ راه‌اندازی اولیه برای تنظیم مجوزها
- راهنمای فعال‌کردن اعلان‌ها
- راهنمای آلارم دقیق
- راهنمای Full-screen notifications
- راهنمای نمایش روی صفحهٔ قفل
- راهنمای غیرفعال‌کردن محدودیت باتری
- راهنمای مخصوص گوشی‌های محدودکننده مثل شیائومی
- امکان بررسی مجدد مجوزها از داخل خود برنامه

### ۷) پایداری و رفتار روی گوشی
- طراحی‌شده برای استفادهٔ آفلاین پس از وجود فایل‌ها داخل برنامه
- داشتن جریان ساخت APK از طریق GitHub Actions
- شامل اصلاحات مربوط به حذف آلارم، انتخاب صدای سفارشی و نمایش تعاملی آلارم روی صفحهٔ قفل
- ساختار برنامه برای کار روی گوشی‌های مختلف اندرویدی در نظر گرفته شده، هرچند نتیجه هنوز به تنظیمات مجوز و محدودیت‌های همان گوشی وابسته است

## چرا این پروژه متفاوت است؟

برخلاف یک اپلیکیشن آلارم معمولی، **Meow Meow Alarm** سعی می‌کند روند بیدارشدن را به یک تجربهٔ شخصی، گرم و کمی بازی‌گونه تبدیل کند.

تمرکز اصلی آن روی این موارد است:
- ظاهر بانمک و صمیمی
- رفتار خاص و به‌یادماندنی آلارم
- تعامل مرتبط با گربه
- شخصی‌سازی واقعی صداها
- کاربردی‌بودن روی اندروید

---

مسیر فعال پروژه این است:
- استفاده از **استایل دوبعدی اصلی**
- حفظ همان صحنهٔ اصلی گربه و مرد
- بهبود قابلیت اطمینان، تنظیمات و کیفیت تجربهٔ کاربر

مسیرهایی که فعلاً کنار گذاشته شده‌اند:

## ساخت APK

برای ساخت APK، مخزن شامل یک GitHub Actions workflow است.

روند کلی:
1. تغییرات را Push کن
2. وارد تب **Actions** در GitHub شو
3. Build اندروید را اجرا یا بررسی کن
4. APK را از Artifacts همان Build موفق دانلود کن

اگر محلی Build می‌گیری، از پروژهٔ اندرویدی داخل پوشهٔ `app/` استفاده کن.

---

## ساختار مخزن

```text
app/                     سورس اپلیکیشن اندروید
app/src/main/assets/     رابط HTML / CSS / JavaScript
app/src/main/java/       کد Kotlin سمت اندروید
app/src/main/res/raw/    فایل‌های صوتی داخلی
.github/workflows/       ورک‌فلو ساخت APK در GitHub
tests/                   تست‌ها و اسکریپت‌های بررسی
docs/                    مستندات
```
