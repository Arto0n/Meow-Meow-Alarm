# Change notes

The repository has evolved through a series of experimental builds and fixes. Git commit history is the authoritative chronological record.

## Current development line

- Original cozy illustrated 2D scene (pixel and 3D experiments are not the preferred direction).
- Multiple alarms, alarm editing, deletion and snooze.
- Six built-in meows and three built-in purr sounds, with custom import and per-alarm meow overrides.
- Cat name and appearance selection.
- Lock-screen alarm interaction and a first-run permissions guide.

## Repository housekeeping

- Standard GitHub `README.md` added.
- Requirements, build instructions, permissions, troubleshooting, and rights notes documented.
- Outdated root-level upload instructions consolidated into the new docs.

This document does not attempt to assign release dates or claim successful physical-device testing where no test evidence is available.
