# Meow Meow Alarm — Android Preview

Download the attached **APK** below to install the app on Android 8 or newer.

Features include multiple alarms, per-alarm sound selection, six meow presets, three purr presets, custom audio, a customizable cat, and an interactive wake-up screen.

**Before relying on alarms:** grant notification, exact-alarm and full-screen alarm permissions when prompted, and test an alarm while your phone is locked.

**Preview build:** This APK is debug-signed by GitHub Actions. The signing key may differ between builds; you might need to uninstall an older preview to install this one. Uninstalling can delete saved alarms and settings. A separately signed production release is planned for a future version.
