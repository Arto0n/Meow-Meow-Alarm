# Source and audio rights

Meow Meow Alarm is currently a personal-use project and the repository has **no declared open-source license**.

Being publicly viewable on GitHub does not itself grant others a license to reuse, modify, or redistribute the project's code, artwork, or media.

The project includes user-supplied meow/purr recordings and custom visual assets. The ownership and redistribution license for every media item has not been independently established. Before adding a license or publishing a production APK, verify the provenance and permissions for all distributed sound and image files.

Do not automatically add MIT, Apache-2.0, GPL, CC0 or any other blanket license covering third-party audio without first making a rights decision.
